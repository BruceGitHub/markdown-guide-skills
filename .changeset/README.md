# Changesets

This directory contains the Changesets configuration and pending changesets.

## Workflow

- `npm run changeset` — create a changeset for a user-visible change.
- `npm run version` — apply version bumps, update `CHANGELOG.md`, sync `SKILL.md` and `README.md`.
- `npm run release` — create release tags from the current versions.

See the [Changesets documentation](https://github.com/changesets/changesets) for details.
