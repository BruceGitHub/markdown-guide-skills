## How to add a flow

- Copy the closest existing flow.
- Keep the same structure: Abstract, Index, Flow, Stages, Gates, Branches, References, Constraints, Change history.
- Link presets and templates instead of repeating their content.
- Add a row to the flow table and a change history entry.
- Keep the diagram minimal and the text short.
